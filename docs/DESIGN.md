# Plutus UI Design Tokens

The UI is minimal, clean, typewriter-inspired and enterprise-usable. The user's chosen style takes precedence over the thicker borders in the RawBlock reference.

| Token | Value |
| --- | --- |
| background | #FFFFFF |
| foreground | #000000 |
| neutral | #B5B5B5 |
| burgundy | #800020 |
| celeste | #B2FFFF |
| border width | 1px |
| radius | 0px |
| shadow | none |
| font | IBM Plex Mono / Space Mono, system monospace fallback |

Rules:
- No nested borders, rounded corners, decorative shadows or excessive icons.
- Use compact headers, generous spacing, readable data tables and text-first controls.
- Burgundy: primary emphasis and destructive/urgent messaging when contextualized.
- Celeste: selected/active states. Use appropriate black text for contrast.
- Use visible keyboard focus, high-contrast text and accessible form labels.
- Provide desktop and narrow mobile views of inventory, checkout, and Dashboard.
- Status labels: Available, Borrowed, Demo Lab, Retired; never rely on color alone.
